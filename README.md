# Malorca 2026 – plán cesty 25. 10. – 2. 11. 2026

Tři rodiny (Maradovi, Pavlasovi, Podařilovi), 12 lidí: 5 dospělých a 7 dětí 4–11 let.

- [Plán cesty](https://docek.github.io/malorca-2026/) – lety, první noc u letiště, čtyři varianty základny (A sever, B jihozápad, C střed, D jihovýchod), mapa s dojezdy, denní programy, rozhodnutí, otevřené otázky, zdroje
- [Katalog výletů](https://docek.github.io/malorca-2026/vylety.html) – 82 aktivit s filtry (region, typ, déšť, vhodné pro 4leté), osobní výběr s odesláním do WhatsAppu
- [Praktické informace](https://docek.github.io/malorca-2026/prakticke.html) – doklady, zdraví, peníze, svátky a sezóna, řízení, půjčovny a transfer, počasí, balení

Statický web, žádný build. `assets/style.css` sdílí všechny stránky. Lokální náhled: `python3 -m http.server 8766`.
Stav podkladů: 12. 9. 2026. Hlasování o výletech probíhá ve WhatsAppu, web hlasy neukládá.
